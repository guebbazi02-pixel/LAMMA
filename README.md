# لمّة · Lamma

شبكة اجتماعية خفيفة بالدارجة الجزائرية، مع العربية والفرنسية والإنجليزية.

## ما في هذا المستودع

| المجلد | المحتوى |
|---|---|
| `app/` | مشروع أندرويد يغلّف التطبيق. صفحة التطبيق نفسها في `app/src/main/assets/index.html` |
| `server/` | الخادم: الحسابات والمنشورات والرسائل والإشراف. التفاصيل في `server/README.md` |
| `docs/` | شروط الاستخدام وسياسة الخصوصية كصفحات عامة، وطريقة إنشاء مفتاح التوقيع |
| `.github/workflows/` | البناء التلقائي: اختبارات الخادم، ملف APK للتجربة، وملف AAB الموقّع لـGoogle Play |

## تنزيل نسخة التجربة

https://github.com/guebbazi02-pixel/LAMMA/releases/download/apk-latest/lamma.apk

## الحالة

- التطبيق يعمل على هاتف واحد ويحفظ بياناته على الجهاز. لم يُربط بالخادم بعد.
- الخادم جاهز كنسخة أولى ومختبَر، ولم يُنشر على استضافة.
- نسخة Google Play الموقّعة تحتاج مفتاح توقيع: انظر `docs/SIGNING.md`.
- نصوص الشروط والخصوصية مسودة، وتحتاج مراجعة قانونية قبل النشر الرسمي.
